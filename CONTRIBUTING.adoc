= Contributing

This document contains development information. It's expected that all
contributors read this documentation in its entirety before contributing to
this infrastructure provider.

== Requirements

* https://nixos.org/[Nix] with
https://nixos.wiki/wiki/Flakes[flakes enabled].

== Development

The `Makefile` is the primary method of interfacing with this project. Refer to
its targets for more information.

Enter the development shell before running development commands. The shell
provides the pinned versions of Go and Make used by the project.

[source,shell]
----
nix develop
----

Build the infrastructure provider binary.

[source,shell]
----
make build
----

The binary is written to `bin/omni-infra-provider-oxide`.

=== Running Locally

. Export the necessary environment variables.
+
[source,shell]
----
export OMNI_ENDPOINT=https://example.na-west-1.omni.siderolabs.io:443
export OMNI_SERVICE_ACCOUNT_KEY=ZXhhbXBsZQ==
export OXIDE_HOST='https://oxide.sys.example.com'
export OXIDE_TOKEN='oxide-token-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX'
----

. Run the infrastructure provider.
+
[source,shell]
----
make dev
----

== Running Tests

Run the unit tests locally.

[source,shell]
----
make test
----

== Building Release Artifacts

Build a local snapshot of the release archives and checksums.

[source,shell]
----
make snapshot
----

GoReleaser writes Linux and Windows archives for amd64 and arm64, and a macOS
archive for arm64, to `dist/`. Linux and macOS artifacts use the `tar.gz`
format, while Windows artifacts use `zip`.
